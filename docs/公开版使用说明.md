# 共读空间公开版使用说明

## 这是什么版本

这是一个面向自部署用户的通用共读空间。界面不绑定任何具体模型、平台或私人角色名，新产生的 AI 批注统一保存为：

```json
{ "author": "assistant" }
```

为了保护旧数据，历史记录中的 `claude`、`ember` 仍会被识别为共读伙伴，但系统不会再主动写入这些值。

## 第一次进入

第一次打开阅读页时，会出现轻量设置：

- 空间名称
- 读者昵称
- 共读伙伴昵称
- 欢迎语

保存后会写入 `data/room-config.json`。同一部署在手机、平板和电脑上会显示相同名称。之后可点击书架右上角的齿轮再次修改。

### 自定义应用图标

空间设置中可以选择 PNG、JPEG 或 WebP 图片作为应用图标。浏览器会自动从图片中央裁成正方形并保存为 `data/app-icon.png`，用于浏览器标签页以及支持网页图标读取的 Aru Apps 和 Dock。

- 建议选择主体居中、边缘留有少量空白的正方形图片。
- 自定义图标保存在持久化数据目录中，重新部署后仍可保留。
- 点击「恢复默认」可以换回公开版内置图标。
- `/app-icon.png` 会被公开读取，以便 Aru 在没有书房 Token 的情况下下载图标；书籍、批注、设置与其他接口仍受 Token 保护。

## 一键启动

```bash
cp -R data.example data
MCP_AUTH_TOKEN="换成你自己的长随机字符串" npm start
```

本地打开：

```text
http://127.0.0.1:3100/?token=你的MCP_AUTH_TOKEN
```

每台新设备第一次使用带 Token 的地址；验证成功后，平时直接打开普通地址即可。

## Zeabur 部署

1. 上传代码或连接代码仓库。
2. 启动命令使用 `npm start`。
3. 添加环境变量 `MCP_AUTH_TOKEN`，值使用足够长的随机字符串。
4. 给 `READING_MCP_DATA_DIR` 指向的目录挂载持久化存储；否则重新部署可能丢失书籍、批注、进度、空间设置和自定义应用图标。
5. 首次访问 `https://你的域名/?token=你的Token`。

Zeabur 会自动提供 `PORT`，一般不需要手动填写。

## 数据边界

一套部署对应一个共读空间和一份数据目录。知道同一 Token 的访问者会看到同一书架、进度和批注。

如果不同用户需要彼此隔离的私人书房，应分别部署，或为每个实例使用不同的数据目录。本版本不是带账号系统的多租户平台。

## 从旧版迁移

可直接复制旧版 `data/` 目录。书籍、批注、回复、卡片、进度和阅读位置格式保持兼容。第一次进入公开版时只需补充空间设置，不会重写旧批注。
